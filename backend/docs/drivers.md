# จัดการพนักงานขับรถ

หัวหน้าขนส่งใช้เมนู **พนักงานขับรถ** เพื่อเพิ่ม/แก้ไขชื่อ เบอร์โทร อีเมล ตำแหน่ง วันที่เริ่มงาน ใบขับขี่ และสถานะพนักงาน

## ทดลองด้วย Postman

Import `postman/drivers.postman_collection.json` แล้วเรียกตามรายการ ไฟล์ใช้ `supervisor_id` ของหัวหน้าขนส่งตัวอย่าง และบันทึก `employee_id` หลังสร้างให้อัตโนมัติ เปลี่ยนอีเมลกับเลขใบขับขี่ก่อนเพิ่มคนใหม่ เพราะต้องไม่ซ้ำ

POST `/drivers` ตัวอย่าง:

```json
{
  "supervisor_id": "DEMO-USER-SUP",
  "name": "คนขับทดลอง",
  "phone": "0812345678",
  "email": "driver.new@example.test",
  "position": "พนักงานขับรถ",
  "hire_date": "2026-09-04",
  "license_number": "TEST-LICENSE-002",
  "license_expiry": "2030-09-04",
  "status": "active"
}
```

ตอบ `201` พร้อม `employee_id` และ `user_id` ที่สร้างให้เอง ข้อมูล User และ Driver บันทึกใน transaction เดียว ไม่สร้างบัญชีค้างเมื่ออีเมล/ใบขับขี่ซ้ำ (`409`) รหัสผ่านเป็นค่า disabled ไม่ใช่รหัสสำหรับเข้าสู่ระบบ

PATCH `/drivers/:employee_id` ส่งเฉพาะข้อมูลที่เปลี่ยน พร้อม `supervisor_id` เช่น `{"supervisor_id":"DEMO-USER-SUP","status":"suspended"}`

- `active` ทำงานอยู่, `suspended` พักงาน, `resigned` ลาออก
- พักงาน/ลาออกไม่ได้ขณะยังมีงาน รวมงาน `on_hold` ต้องจบงานหรือเปลี่ยนผู้รับงานก่อน (`409`)
- ใบขับขี่หมดอายุบันทึกเป็นประวัติได้ แต่รับงานใหม่ไม่ได้ วันหมดอายุยังถือว่าใช้ได้ทั้งวันตามเวลาไทย ไม่ตรวจสอบข้อมูลกับหน่วยงานออกใบขับขี่
- `active_request_id` บอกงานปัจจุบัน และ `eligible` บอกว่าข้อมูลครบ ทำงานอยู่ และว่างรับงาน
- ไม่มี API ลบพนักงาน เพื่อคง FK และประวัติการมอบหมาย
- ข้อมูลเดิมยังอยู่ สถานะเริ่มต้น `active` ส่วนใบขับขี่เดิมเป็น null ให้หัวหน้าขนส่งเติมตามจริง ไม่สร้างเลขใบขับขี่สมมติให้ข้อมูลเก่า งานที่มอบหมายอยู่ดำเนินต่อได้ แต่การมอบหมาย/แก้ปัญหาด้วยรถใหม่จะตรวจความพร้อมใหม่
- Seed เพิ่มใบขับขี่ตัวอย่างเฉพาะคนขับ DEMO ที่เพิ่งสร้าง และไม่เขียนทับข้อมูลเดิม

สิทธิ์ในเว็บแสดงเมนูเฉพาะหัวหน้าขนส่ง API ตรวจว่ารหัสผู้ดำเนินการเป็นหัวหน้าขนส่งที่มีอยู่ ระบบยังไม่มีการยืนยันตัวตนจาก session/token จึงยังใช้เป็นระบบล็อกอินจริงไม่ได้ เมื่อทีมเพิ่มล็อกอินต้องอ่านผู้ดำเนินการจากตัวตนที่ยืนยันแล้วแทน `supervisor_id` ใน Body
